# 마이링크 (MyLink) 텍스트 와이어프레임 (Wireframes)

본 문서는 링크트리 클론 서비스 **마이링크(MyLink)**의 핵심 화면 구조 및 UI/UX 설계를 시각화한 텍스트 와이어프레임입니다.

---

## 1. 크리에이터 관리자 대시보드 (`/admin`) — 2분할 에디터

데스크톱 기준 좌측은 **탭 기반 편집 패널**, 우측은 **실시간 반응형 스마트폰 목업**으로 구성됩니다.

```text

├───────────────────────────────────────────────┬─────────────────────────────────────────────────┤
│  [좌측: 편집 패널]                             │  [우측: 실시간 모바일 목업 프리뷰]              │
│                                               │                                                 │
│  ┌────────────┬──────────┬──────────┬────────┐│              ┌───────────────────┐              │
│  │ 🔗 링크관리 │ 🌐 SNS   │ 🎨 테마   │ 📊 통계 ││              │    ╭─────────╮    │              │
│  └────────────┴──────────┴──────────┴────────┘│              │    │ (•)  ── │    │ (스마트폰     │

│  ┌─ 링크 1 ───────────────────────────────┐  │              │    민지의 패션로그 │              │
│  │ [::] 제목 : [ 🔥 이번 주 최저가 마켓 바로가기 ]│  │              │ 매주 뷰티&패션 팁 ✨│              │
│  │      URL  : [ https://market.com/minji   ]│  │              │                   │              │
│  │                                        │  │              │ [📸] [▶️] [🎵] [✖️] │ (SNS 바)     │
│  │  [▲ 순서위] [▼ 순서아래]  노출 [🟢 ON]  [🗑️]│  │              │                   │              │

│  │ [::] 제목 : [ 🎬 가을 룩북 브이로그 (YouTube) ]│  │              │ ┌───────────────┐ │              │
│  │      URL  : [ https://youtu.be/xyz123   ]│  │              │ │ 🎬 룩북 유튜브  │ │              │
│  │                                        │  │              │ └───────────────┘ │              │
│  │  [▲ 순서위] [▼ 순서아래]  노출 [🟢 ON]  [🗑️]│  │              │ ┌───────────────┐ │              │
│  └────────────────────────────────────────┘  │              │ │ 📝 데일리 블로그│ │              │
│                                               │              │ └───────────────┘ │              │
│  ┌─ 링크 3 (숨김 상태) ───────────────────┐  │              │                   │              │
│  │ [::] 제목 : [ 📝 지난 이벤트 당첨자 발표   ]│  │              │  ⚡ Powered by    │              │
│  │      URL  : [ https://blog.naver.com/... ]│  │              │     마이링크      │              │
```

## 2. 방문자 공개 프로필 페이지 (`/[username]`) — 모바일 뷰

팬들이 스마트폰(인스타그램 인앱 브라우저 등)에서 접속했을 때 보게 되는 최종 화면입니다.

```text
               ┌──────────────────────────────┐
               │         12:30  5G 🔋         │
               ├──────────────────────────────┤
               │                              │
               │            ( 👤 )            │
               │                              │
               │        민지의 패션로그       │
               │  매주 수/일 패션 & 뷰티 팁 ✨ │
               │                              │
               │     [📸]  [▶️]  [🎵]  [💬]    │  <- 공식 SNS 아이콘
               │                              │
               │ ┌──────────────────────────┐ │
               │ │ 🔥 이번 주 최저가 마켓 ↗ │ │  <- 메인 강조 링크
               │ └──────────────────────────┘ │
               │                              │
               │ ┌──────────────────────────┐ │
               │ │ 🎬 가을 룩북 브이로그 ↗  │ │
               │ └──────────────────────────┘ │
               │                              │
               │ ┌──────────────────────────┐ │
               │ │ 📝 데일리 코디 블로그  ↗ │ │
               │ └──────────────────────────┘ │
               │                              │
               │                              │
               │        ⚡ Powered by         │
               │       마이링크 (MyLink)      │  <- 무료 만들기 유도
               │                              │
               └──────────────────────────────┘
```
